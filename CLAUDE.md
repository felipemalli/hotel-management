# Regras de sessão (carregado automaticamente — leia antes de qualquer coisa)

1. **A fonte da verdade é versionada e pública.** Leia antes de criar ou editar qualquer arquivo: `docs/CHALLENGE.md` (§1 desafio numerado, §2 matriz RF/RN, §3 tabela T1–T9, §4 leituras do enunciado, §6 escopo), `docs/BUSINESS_RULE.md` (RN1–RN27) e `docs/ARCHITECTURE.md` (camadas, grafo, §7 contrato da API, gatilhos). Detalhe por assunto: `docs/concepts/` (AUTH, IRIS, QUALITY) e `docs/code/`. O `README.md` é só a porta de entrada: subir, executar, testar e links. Não existem mais `ai-plans/`, `RESUMO-DO-PROJETO.md`, `backend/docs/`, `docs/DECISOES.md` (D1–D19 viraram RN7–RN27) nem `docs/COMO-RODAR.md` — removidos de propósito em 06–07/09/2026; se algum texto os citar, o texto está velho.
2. **O código e a suíte são o árbitro.** Documento que divergir do código é o documento que se corrige — e a correção é ativa: **pare, reporte** o que propõe mudar e nunca contorne em silêncio. Vale para versão de lib, forma da API e comportamento observado.
3. **Invariantes inegociáveis** (`docs/ARCHITECTURE.md` §4 e §6): dinheiro é `Decimal`, nunca `float`; relógio injetável (`now`/`today` por parâmetro, só a view lê `timezone.now()`); TZ `America/Sao_Paulo` com toda regra de horário decidida em hora local; camadas `models → selectors → services → serializers → views`, com toda mutação e todo dinheiro no service.
4. **A tabela T1–T9 (`docs/CHALLENGE.md` §3) e os ids da matriz (`docs/CHALLENGE.md` §2) são imutáveis.** Se um teste seu não bate com T1–T9, o erro está no seu código. Os ids têm guarda própria em `.github/workflows/ci.yml` ("Guard - normative test ids exist"): renomear um caso quebra o CI, então a matriz muda primeiro.
5. **Comentários:** leia `backend/.claude/skills/lean-comments/SKILL.md` (ou o gêmeo em `frontend/`) antes de editar código. Atenção à exceção, que é onde se erra: **preserve o porquê não-óbvio** — lock, invariante surpresa, por que *não* a solução aparente, contrato de caller (N+1, precisão de coluna). Diretiva de ferramenta (`# pragma: no cover`, `# Generated by`) não é comentário e não se remove. Cortar esses é regressão, não enxugamento.
6. **Backend:** antes de criar ou editar Python em `hotel/`, `accounts/`, `core/`, `ai/` ou `config/`, leia `backend/.claude/skills/backend-layers/SKILL.md`. `backend/CLAUDE.md` tem a tabela.
7. **Frontend:** antes de mexer em teste, componente de UI ou primitivo shadcn, leia a skill em `frontend/.claude/skills/` (`testing-frontend`, `frontend-ui-components`, `adding-shadcn-component`). `frontend/CLAUDE.md` tem a tabela de quando ler cada uma.
8. **Como subir e verificar:** o `README.md` tem os comandos canônicos das quatro suítes. O backend **não tem bind mount**: `docker compose exec backend pytest` testa a imagem, não a sua árvore — use o caminho nativo (`cd backend && set -a && . ../.env && set +a && uv run pytest …`) ou rebuilde a imagem. Cole a saída completa na conversa quando a tarefa exigir prova.
9. **Commits:** Conventional Commits em inglês, 1 unidade revisável, suíte verde, sem trailers de atribuição, e sem mencionar agente no texto. **Proibido:** `git add -A` sem revisar `git status` antes, `git add -f`, e commitar o que está no `.gitignore` — hoje `.env`, `desafio.md` e artefatos de build (`.venv/`, `node_modules/`, `dist/`, `htmlcov/`, `frontend/e2e/.auth/`, `.claude/settings.local.json`). `CLAUDE.md`, `backend/CLAUDE.md` e `frontend/CLAUDE.md` **são** rastreados de propósito, junto com as skills: o `README.md` declara o uso de agentes sob revisão humana.

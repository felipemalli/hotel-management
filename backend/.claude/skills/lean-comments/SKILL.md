# Comentários

Não comentar. Exceção: o porquê não-óbvio, 1–3 linhas — lock, invariante surpresa, por que não o aparente.

Cortar: docstring de módulo; narrar a linha seguinte; ensaio de design; banners de seção; citações SPEC/RF/D.

Docstring de função: uma linha só se o contrato do caller não for óbvio. Senão, nenhuma.

Testes: o nome mapeia o requisito. Comentário só em assertion surpreendente.

Não são comentário (manter): OpenAPI, mensagens de erro, help_text, `# Generated by`.
